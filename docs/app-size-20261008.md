# Alleggerimento dell'app — 8 ottobre 2026

Versione verificata: **1.0.0+2**, identificatore **com.vibra.app**.
Il download Android stimato per la configurazione confrontata diminuisce del
**31,23%**. La build iOS senza firma diminuisce dell'**1,24%**.

## Modifiche

- Eliminati il client Spotify precedente, repository, modelli generati e provider inutilizzati, insieme al plugin nativo `flutter_appauth`. Il login PKCE corrente, il rinnovo dei token e la sincronizzazione via backend restano operativi nei test.
- Eliminati i client Ticketmaster/Songkick disattivati e il relativo mapping. I cataloghi gestiti dal backend restano disponibili.
- Rimossa `google_fonts`: Flutter carica direttamente Inter e Syne. Le varianti incluse passano da dieci a sette, conservando i pesi usati nell'interfaccia e le licenze OFL.
- Attivati R8 e la rimozione delle risorse inutilizzate nelle release Android, usando `proguard-android-optimize.txt`. La procedura store conserva anche `mapping.txt` per interpretare gli errori della build ottimizzata.
- Eliminati le cartelle asset vuote e la GIF dimostrativa del package mappe, circa 43,9 MiB nel repository. La GIF non entrava nel pacchetto mobile e non è conteggiata nel risparmio dell'app.

La configurazione Android segue la [documentazione ufficiale R8](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization).

Il download è stimato da bundletool 1.18.3 per ARM64, API 36, densità 420 dpi e
lingue italiano/inglese, usando APK firmati con la chiave debug per la sola QA.
La procedura è descritta nella [documentazione bundletool](https://developer.android.com/tools/bundletool).
La dimensione effettiva sugli store dipende dal dispositivo e dal pacchetto
firmato. Il download App Store non è stato misurato.

L'AAB comprende tutte le architetture, i simboli nativi e i metadati R8:
la sua dimensione complessiva non rappresenta quanto scarica un singolo telefono.
Le misure ARM64 escludono le altre architetture e i metadati diagnostici.

## Verifiche

- `flutter analyze`: nessuna segnalazione; tutti i **134 test** unitari/widget superati. Rimossi due test del solo interceptor Spotify dismesso; conservati i controlli sul flusso OAuth attuale e sull'isolamento degli account.
- Android: compilazione release e ottimizzazione R8 completate; firma store fermata correttamente dall'assenza del keystore ufficiale.
- APK release ottimizzati generati con bundletool, installati nella copia temporanea dell'emulatore Android API 36. Avvio fino alla schermata iniziale e richiesta notifiche verificato, senza errori Flutter o di registrazione plugin nei log osservati.
- Tutte le 12 librerie native rispettano l'allineamento ELF da 16 KB. Tutti i cinque APK split della configurazione QA superano anche `zipalign -c -P 16 -v 4`. L'emulatore usato ha pagine da 4 KB: resta necessaria la prova su dispositivo da 16 KB.
- iOS: build release senza firma riuscita; verificati sette font, assenza di `flutter_appauth.framework`, versione, bundle ID e manifest privacy.
- Scansioni: 443 file Android e 219 file iOS, nessun segreto noto o residuo dei plugin demo/test rilevato. Preflight tecnico superato.

Report numerico, scansioni, simboli R8 e copie diagnostiche aggiornate sono in
`release/`, esclusa da Git. Gli artefatti senza firma e gli APK con firma debug
sono destinati alla verifica tecnica. I prerequisiti di pubblicazione restano
elencati in [preparazione store](store-readiness-20261007.md).
