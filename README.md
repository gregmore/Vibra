# Vibra

**Don't just listen to music. Live it.**

## Quick Setup

1. Create an `.env` file from `.env.example` and fill in the keys:
   - `SUPABASE_URL`, `SUPABASE_ANON_KEY`
   - `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`
   - (Optional) `TICKETMASTER_API_KEY`, `SONGKICK_API_KEY`, `BANDSINTOWN_APP_ID`

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Generate code files (Freezed/JSON/Riverpod):
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

## Testing

### Unit & Widget Tests
```bash
flutter test
```

### Integration Test (Emulator/Device)
```bash
flutter test integration_test/spotify_oauth_flow_test.dart
```

*Note: The Spotify OAuth test is **mocked on the UI side** (it does not actually open the AppAuth browser).*

## Edge Functions

Main functions connected to external services:
- `recommend-events`
- `calculate-match`
- `send-notifications`
- `spotify-token-exchange`
- `sync-music-profile`

For deployment and real execution, the following Supabase Edge environment variables are required:
- `SUPABASE_SERVICE_ROLE_KEY`
- `SUPABASE_ANON_KEY`
- `SPOTIFY_CLIENT_SECRET`
- `FCM_SERVER_KEY` (only if you want real FCM push notifications)
