# Vibra Brand Pack

Asset inclusi:

- `vibra_app_icon.svg`
  - uso consigliato: base per icona app, adaptive icon, favicon, social avatar
- `vibra_splash_visual.svg`
  - uso consigliato: splash artwork, launch promo, onboarding hero
- `vibra_store_hero.svg`
  - uso consigliato: visual promo store, feature graphic, banner marketing

Direzione visiva:

- sfondo dark premium
- palette viola profondo + magenta + cyan
- simbolo centrale audio/live coerente su tutti gli asset
- stile pulito, tech-music, high contrast

Passi successivi consigliati:

1. esportare `vibra_app_icon.svg` in PNG 1024x1024 per store icon
2. adattare `vibra_store_hero.svg` ai formati richiesti da App Store / Play Console
3. usare `vibra_splash_visual.svg` come riferimento per asset splash definitivi nativi
